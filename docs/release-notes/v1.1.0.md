**Your AI agents fight in your taskbar - and now they teach themselves new moves.**

Everything built since v1.0.0 (2026-10-16): fighters that learn, sharper fights frame by frame, a settings window and
first-run guide, streamer mode, stats cards and achievements, more AI programs detected, and Windows that works on any
taskbar edge and any DPI.

The Windows zip is not code-signed, so SmartScreen may ask once: click **More info**, then **Run anyway**. Run one copy at a
time: the zip, a pip install and a git checkout share one data folder, so `stop` one before starting another.

## New

- **Fighters learn.** Each program's fighter grows its own move set from what really happens to it on the taskbar - moves
  generated from its existing poses, held to the same quality bar as the shipped art, offline and numbers-only. See them
  with `python minis.py learned` ([docs/LEARNING.md](https://github.com/mrktchris/taskbar-fighters/blob/v1.1.0/docs/LEARNING.md)).
- **Fight quality, frame by frame.** Hitlag that freezes both fighters by damage, real spacing (bodies never sink into each
  other), no pops between moves, cleaner pixels, and a throw slam without the white flash.
- **Settings window, first-run guide and hover cards.** A pixel-art settings window (tray > *Settings...*), a one-time guide
  to the fighter, plates and scoreboard, and hover cards with each program's state in words.
- **Replays and fight codes.** Replay the last K.O. in slow motion, export it as a GIF, and share a fight code.
- **Move book.** Every move, set piece and finisher per fighter (tray > *Move book...*).
- **Streamer mode** - a normal window OBS can capture (`python minis.py stream on`).
- **Stats card, careers, ranks and 22 achievements** (`python minis.py card`, `python minis.py achievements`).
- **More AI programs detected**, including the Claude desktop app as its own program.
- **Community skin packs** - a documented, data-only format (`python minis.py packs`).
- **Optional sound effects**, off by default (`python minis.py sound on`).

## Fixed

- **A hidden fighter stays out of the fight.** Before, the visible one could fight, and be K.O.'d by, an opponent you had
  hidden. A bout already running stops on both sides.
- **Windows on other people's PCs.** The taskbar can be on any edge, the empty stretch is found from the taskbar's own
  layout, per-monitor DPI is handled, and the fighters re-place themselves after a display, DPI or Explorer change.
- **Arena.** Runs at 30 fps (trimmed sprites, faster redraws), and the freeze-mode hole is no longer repainted short.

## Privacy

Unchanged: agent activity is read from local files and the process list as numbers only. Nothing leaves your computer.
