# V4 work order (2026-10-13) - binding for both builders

## The author's asks (his words, condensed) + his answers
Make fighting look awesome: enhanced effects. Higher definition (go up bits if needed). Anime-style special attacks (a charged beam, a spinning orb, a crescent wave, a grapple dash, ground claws, a power-up, a rising ball). A taskbar thing on the RIGHT. Winners: random OR decided -> **both, with a switch** (default decided). Platform-fighter / anime-battle **arena mode**: fighters break out of the taskbar and fight across the screen, interact with active windows, throw letters, "destroy programs" - ANIMATED ONLY, nothing real happens. Arena FX chosen: **cracks + shatter on a window, letters flying off windows, explosions + screen shake, freeze the 2nd monitor as the stage**. Arena screen: **ask each time** (`--monitor N`). Resolution: **2x rig, 128px cells, <= 64 colours** for the arena; taskbar keeps the 64px version.

## Hard rules (unchanged + arena-specific)
- Visual only. Arena NEVER closes, moves, minimizes, focuses or sends input to any real window; it only reads window RECTANGLES (EnumWindows/GetWindowRect of visible top-level windows). Window TITLES are never read into display, logs, bus or files. Letters thrown are random glyphs, never text from the screen.
- Freeze backdrop = screenshot of the chosen monitor kept ONLY in RAM for the arena's lifetime; never written to disk, never logged, never sent. Builders/testers never capture a monitor into an LLM context; tests use synthetic backdrops.
- Opt-in and stoppable: `minis.py arena --monitor N [--freeze] [--seconds S]`, right-click "Arena mode...", stop with ESC (when the overlay has focus), the on-screen EXIT button, `minis.py arena stop`, or `minis.py stop`. Arena overlay is click-through except the EXIT button. Never interferes with the taskbar fighters' own rules; pausing pauses the arena too.
- Read-only telemetry, numbers/enums only, no network, never touch Claude/Codex settings/hooks, writes only in this folder and %LOCALAPPDATA%\minis, `stop` only kills processes it can prove are its own. Never run full-screen captures while developing (taskbar rows / own windows only).

## Shared interfaces (ART builds, ENGINE consumes - both must match exactly)
### HD assets
`art/rig.py` gets a resolution factor `RES` (1 = today's 64px cell, 2 = 128px cell; all body dims, GROUND, HIP_X, glyphs, fx scale with it; HD may add detail: 2px outlines where it reads better, extra shading tone, bigger sigils). Build both: `assets/<character>/` (RES 1, cap 32 colours, unchanged look) and `assets_hd/<character>/` (RES 2, cap 64 colours). `anim.json` identical schema plus `"res": 2`, `"cell": [128,128]`, `"ground_y"`, `"anchor"`. `minis_core/atlas.Atlas(character, root=..., hd=True)` loads assets_hd.
### Ultimates (every character gets exactly one `ultimate` in `signature`: {"strike","special","super","ultimate"})
Anime homage moves, original art (no copied sprites). Assign: claude=`radiant_beam` (two-hand charge 1.2 s, then a horizontal beam), codex=`spiral_orb` (spinning sphere in hand, dash-in hit, spiral burst) + `shadow_clones` support (3 dithered clones that rush), gemini=`crescent_fang` (crescent slash wave, big), cursor=`grapple_strike` (two grapple lines shoot out, zip-dash across, spinning slash), ollama=`gale_rend` (3 ground-ripping energy claws), lmstudio=`awakening` (power-up aura burst, then rapid flash-step strikes), generic=`star_core` (slow rising ball, thrown). Each ultimate = fighter animation rows in the atlas + an **effects sheet** `fx.png` + `fx.json`: `{"effects": {"<name>": {"frames":[{"x","y","w","h","ms"}], "anchor":"hand|ground|center", "offset":[dx,dy], "loop":false, "layer":"front|back", "hit_frame":n, "travel":{"speed":px/s}|null, "shake":{"frames":n,"amp":px}|null}}}`. Beams/waves may be any width (e.g. 256x48 in HD). Also generic effects for everyone: `hit_light`, `hit_heavy`, `block_spark`, `dust`, `ko_stars`, `crack_small`, `crack_big`, `shatter` (shards as separate frames), `explosion`, `letters` (a 26-glyph set, 2 sizes), `ko_text` ("K.O."), `round_text` ("ROUND 1/2/3", "FIGHT!", "WINNER").
### Rounds and winners
Bout = best-of-3 rounds. Each round: both fighters have an HP bar (100). Damage per move = power (1/2/3) * 12, ultimate = 40; a round ends at 0 HP or after 25 s (higher HP wins). Who lands what is seeded: in `decided` mode the seed is biased by health score = (100 - ctx%) + (not at limit ? 20 : 0) + (working ? 10 : 0), ties random; in `random` mode unbiased. Match winner: `victory`/`victory2` + "WINNER" text, loser `knockdown`. Record W/L per character in `%LOCALAPPDATA%\minis\record.json` (atomic). Switch: `minis.py winners random|decided` -> control.json `winners`; right-click toggle.
### Right-side taskbar widget (scoreboard)
A third small layered window at the RIGHT end of the empty stretch (just left of the icon cluster / tray; config `scoreboard_x`): shows "A W-L  vs  B W-L", the current mode (taskbar / arena / paused), round HP bars during a bout, and 3 click buttons: Pause/Resume, Arena, Bout now. Lives in the director process. Never shows titles or content.
### Arena mode (`minis_core/arena.py` + `minis_win/arena_window.py`)
One full-monitor layered topmost click-through window on monitor N. Fighters are the HD atlases at 2x scale (so ~170 px tall). Stage: platforms = the top edges of visible windows' rects on that monitor (+ the floor = taskbar top / monitor bottom); fighters jump/fly between them anime-style (air dashes, afterimages, hover). Window interaction (all overlay): a strike that lands while the defender overlaps a window rect draws `crack_small` at the impact; a heavy/ultimate draws `crack_big`; 3 cracks on the same window -> `shatter` (shards fall off the overlay) and `letters` spray; explosions + `shake` offset the whole overlay for N frames. With `--freeze`: snapshot the monitor to RAM, paint it as the backdrop (full opacity), fighters break it; shatter reveals a dark hole in the backdrop. EXIT button top-right. Entry animation: taskbar fighters hide, HD fighters "burst out" of the taskbar position upward. Exit: reverse, taskbar fighters reappear. Runs as its own process `minis.py run arena ...` so a crash never takes the taskbar down.
